Factory Inventory Management System

Architecture overview: a Vue 3 single-page app on a FastAPI backend serving in-memory mock data (no database).

System architecture

Frontend

Vue 3 SPA · Vite dev server · port 3000
  • Views: Dashboard, Inventory, Orders, Demand, Spending, Reports
  • Components: FilterBar, detail modals (product, backlog, cost, inventory), profile menu, language switcher
  • Composables: useFilters, useAuth, useI18n (en / ja)
  • Routing: vue-router, 6 routes
  • API client: src/api.js (axios)

Backend

FastAPI · Uvicorn · port 8001
  • Endpoints in server/main.py (read-only GET)
  • Filtering: apply_filters (warehouse, category, status) and filter_by_month
  • Validation: Pydantic response models
  • Aggregation: dashboard totals, quarterly reports, monthly trends computed per request
  • CORS: open to all origins (demo setting)

Data

JSON files · loaded into memory
  • server/mock_data.py reads server/data/*.json once on import
  • inventory, orders, demand_forecasts, backlog_items, purchase_orders, spending, transactions
  • generate_data.py regenerates sample data
  • No persistence: restart resets state

Data flow

  1. User changes a filter. The FilterBar updates shared refs in the useFilters composable (time period, warehouse, category, order status).
  2. View reacts. A watcher in the active view calls getCurrentFilters() and the matching method in src/api.js. Filters set to "all" are omitted from the query string.
  3. Request sent. Axios issues GET http://localhost:8001/api/...?warehouse=&category=&status=&month=.
  4. FastAPI filters in memory. The endpoint applies apply_filters and filter_by_month to the lists loaded by mock_data.py.
  5. Response validated. Pydantic response models check the shape before JSON is returned. Dashboard, report and trend endpoints aggregate first.
  6. Frontend renders. Raw results are stored in refs (for example allOrders, inventoryItems). Computed properties derive chart series, totals and table rows, and the UI updates.

Inventory filters ignore month because inventory records have no time dimension.

Things to know

  • The API base URL (http://localhost:8001/api) is hard-coded in client/src/api.js.
  • Data is read-only. The backend defines a purchase-order request model but exposes no write endpoints.
  • The current user in useAuth is mock data, not real authentication.
  • Changing the JSON data shape requires updating the matching Pydantic model.
